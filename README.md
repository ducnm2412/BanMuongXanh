# banmuongxanh

Dự án Next.js (App Router) + React 19.

## Scripts

- `npm run dev` — chạy dev server tại http://localhost:3000
- `npm run build` — build production
- `npm run start` — chạy bản build production
- `npm run lint` — kiểm tra ESLint

## Cấu trúc

- `src/app/` — routes (App Router): `layout.jsx`, `page.jsx`, CSS
- `src/assets/` — ảnh import trong code (dùng với `next/image`)
- `public/` — file tĩnh phục vụ trực tiếp tại `/`
